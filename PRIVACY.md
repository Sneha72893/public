### 1. Overview
Incident Response Automation ("the App") is an Atlassian Forge application designed to automate incident tracking and post-mortem generation between GitHub Actions, Jira Cloud, and Confluence Cloud. We are committed to protecting user privacy.

### 2. Information We Do NOT Collect
* We do NOT collect, sell, or monetize any personal data.
* We do NOT collect end-user passwords, payment information, or personal identities.
* We do NOT transmit data to any external, third-party databases or analytics tracking services.

### 3. Data Storage & Hosting
* **100% Hosted on Atlassian Cloud:** The App is built entirely on Atlassian Forge. All app configuration and operational metadata (such as Jira ticket keys, workflow run IDs, and SLA timestamps) are stored exclusively within the customer's own Atlassian tenant using Atlassian Forge Key-Value Storage.
* Data never leaves the secure boundaries of Atlassian's cloud infrastructure.

### 4. Third-Party Integrations
* **GitHub Actions:** Read-only access to workflow run status and logs via secure webhooks for the purpose of incident creation.
* **Slack / Microsoft Teams:** Outbound webhook notifications sent exclusively to customer-configured endpoints.

### 5. Data Retention & Deletion
* Incident records and settings persist only as long as the App is installed on the customer's Jira site.
* Uninstalling the App removes all associated data from the site's storage in accordance with Atlassian's standard retention policies.
